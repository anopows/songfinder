# Security reports

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/anopows/songfinder/security/advisories/new).
Do not open a public issue with exploit details, private recordings, result links, credentials or personal information.

Include the affected version or URL, expected and observed behavior, and the smallest reproducible example using synthetic or public media. Please test only data you own or have permission to use. Send credentials only if the maintainer explicitly requests a secure transfer; normally they are unnecessary.

Security fixes target the latest release and the hosted service. Older releases may require upgrading. This is a personally maintained project, so there is no guaranteed response time.
